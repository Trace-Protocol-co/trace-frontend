Design and prototype a cinematic, trust-first web application called TRACE.

TRACE is an authenticity and provenance network for media built on Sui + Walrus.

The product verifies the origin, integrity, and edit history of photos and videos using cryptographic proofs, decentralized storage, and provenance graphs.

This is NOT a crypto dashboard.

It should feel like:

* Apple security UI
* Linear
* Arc Browser
* Palantir Gotham
* investigative journalism tooling
* cinematic cyber-forensics

The aesthetic should communicate:
trust, permanence, authenticity, intelligence, provenance, evidence, verification, and protocol-level security.

CORE BRAND FEELING:
“HTTPS for media.”

2. HOW IT WORKS

---

Three-step horizontal flow:

CAPTURE
Media signed at creation.
Timestamped using Sui consensus clock.

STORE
Original encrypted media stored permanently on Walrus with blob certificates.

VERIFY
Anyone can inspect provenance history, detect modifications, and verify authenticity.

Use animated diagrams.
Minimal text.
Premium motion design.
